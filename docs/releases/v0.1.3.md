# deepseek harness shell v0.1.3

本版本主要完善桌面应用生命周期、Session 导出体验和更新可靠性，并补充完整的中英文项目文档。

## 更新内容

- 新增系统托盘和单实例机制。关闭主窗口后应用保持运行，可从托盘重新唤起；只有从托盘退出才会结束应用并回收 `dsh` 进程树。
- 新增原生 Session ZIP 导出。桌面壳直接接管导出请求，使用系统保存对话框下载，不再打开浏览器页面或额外的下载任务窗口。
- 提升 macOS 应用内更新的稳定性。GitHub Release 下载支持断点续传，版本检查超时为 120 秒，更新下载连续空闲 3 小时后才判定失败。
- 统一应用名称、托盘图标和窗口唤起行为，并增加相关回归测试。
- 重写项目文档。`README.md` 作为英文入口，`README_ZH.md` 提供中文版本，并新增中英文界面截图、安装说明、打包流程和排错指南。
- CI 新增 Go 测试步骤，在构建三平台安装包前先验证桌面壳逻辑。

## 升级说明

- macOS 可使用应用内更新，更新器会自动选择与当前架构匹配的 `.app.zip`。
- Windows 和 Linux 需要下载并安装对应平台的新版完整安装包。
- 发布包仍自带目标平台的 Node.js 运行时和 `dsh` 生产依赖，用户无需额外安装 Node.js。
